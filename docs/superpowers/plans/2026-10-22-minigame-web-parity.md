# 最新网页端还原实施记录

用户已明确要求按最新网页端完整还原功能、界面和交互；不含实时语音，仅后台开发，不操作桌面。最新基线 origin/main 6835184，已合入当前隔离分支。

实施顺序：
1. 从实际网页组件/CSS/资源建立结构对照，抽取无 DOM 的共享文案。
2. 新建语义化 Canvas 页面渲染：角色轮播首页、建房人数与阵营卡、五轮任务徽章、两侧席位和中央法坛、固定操作栏、独立弹窗。替换通用列表外观。
3. 对齐建房前设置、练习视角、角色详情、投票选择后确认、任务牌选择后确认、自动战报、任务历史、身份及法宝弹窗。
4. 对齐个人中心、仙友/私聊、房间聊天和管理页面的导航及卡片层级，保留服务端鉴权和破坏性操作确认。
5. 后台运行最新网页端和小游戏的相同数据场景，保存对照画面；跑功能/隐私/布局测试、类型检查、构建和版本包校验。

明确限制：不会把 React DOM 页面当作小游戏包；不会绕过域名校验；不会声称后台模拟等于微信工具或真机验收。允许的平台差异只有微信可信登录、原生键盘/相册/分享及屏幕安全区。语音本轮不实施。

验收记录在 docs/minigame-web-parity.md 持续更新。
