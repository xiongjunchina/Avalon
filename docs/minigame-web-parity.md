# 微信小游戏网页端同步说明

## 基准

本轮以 origin/main `edf53a0` 为网页端基准，合并到 `codex/wechat-minigame` 后实施。仅后台代码开发，未操作桌面、开发者工具或发布后台。

## 已同步

- 首页：原场景背景、品牌文案、角色轮播、圆形法相、账号工具、常规房入口、加入房间及单人演练。
- 建房：5–12 人配置、阵营角色卡、全部现有规则开关；练习配置与线上房间分离。
- 牌局：五行任务卡、座位与队长标识、组队和方向、投票选择及确认、任务卡选择及确认、身份和法宝、刺杀、任务记录、结算。
- 玩家：资料头像、仙友、邀请、私聊、房间聊天、统计、战绩、收藏、复盘和配置预设。
- 管理：总览、用户、房间、对局复盘、兑换码及系统设置；破坏操作保留确认，后台清理管理凭证。
- 练习：复用游戏内核、电脑代操、重新演练、切换视角且不重建当前牌局。
- 背景音乐和音效使用网页资源，默认关闭；实时语音未接入。
- 网页角色说明和法宝文案提取为共享模块；小游戏任务徽章由网页原始图形生成。

## 验证

- TypeScript 类型检查通过；网页构建通过。
- 小游戏 81 项测试、网页 32 项测试通过。

- 无界面 Canvas 截图覆盖 320/390/430 宽度：首页、登录、配置、候场、6人/12人牌局、身份、投票、任务、图鉴、管理。
- 最终审查修复终局退出无效、管理兑换码反馈不可见。

- 使用同一个 `scripts/parity-fixture.ts`：6 人，1号行者为队长，proposing 阶段，0/2 已选。两端人数、身份展示状态、座位、方向、字体与截图尺寸一致。

### 后台重现截图

使用环境变量 `MINIGAME_PLAYWRIGHT_PATH`、`MINIGAME_CHROMIUM_PATH` 指定 Playwright 与 Chromium，执行：

```text
node --import tsx apps/minigame/scripts/capture-web-reference.mjs
node apps/minigame/scripts/render-preview.mjs
node apps/minigame/scripts/compare-web.mjs
```

三个脚本仅启动独立 headless Chromium；不连接用户浏览器，不操作微信开发者工具，API 和 WebSocket 均为本地测试数据。

## 产物和后续验收

`npm run package:minigame -- --version=0.2.1` 生成独立工程与 ZIP。开发者工具应导入新产物中的 project，旧导入目录不会自动更新。

本地代码和无界面截图不等于真机验收。真实微信登录、合法域名/端口、多人联机及上传回执仍需在开发者工具与真机验证。本轮未上传或发布，也未更改云服务器。

基准 `origin/main fb79d84`。本轮仅修改代码、运行独立无界面浏览器；没有连接桌面窗口、微信开发者工具或生产服务器，没有上传。

### 本轮内容

- 私密身份改为横向法相卡、同源身份视野/天机说明、心法、法宝状态及查验确认；关闭或进入后台隐藏私密信息。大图按需加载。
- 表决采用领队、出征符框、往难记录展开、三张选择卡、显式提交、已落印进度；展开记录不清空已选票。
- 任务牌保持网页原有内嵌底部区域；蓝方点失败清空先前成功牌并提示，提交前必须明确选择。
- 终局采用网页内嵌结案横幅、阵营身份标签、公开法相座位、完整复盘及房主再开局入口。
- 个人中心保留四栏目：战绩、历史、收藏、常用设置；资料草稿明确保存，历史分页及收藏筛选保留。预设可在无房间时新建/编辑，房间内保存当前设置摘要。
- 仙友三栏目、文字聊天、快捷短语草稿和显式发送、房间邀请；实时语音及语音转文字不接入。公聊采用底部抽屉。
- 图鉴角色文章、法相大图前后翻阅、完整公开规则文字从网页 GuideRules 生成。开房和等待区设置、辅助确认框和管理员数据分区沿用网页卡片/表单样式。
- 复盘显示公开身份、逐轮队伍、表决总数及允许公开的票型；任务牌始终只显示汇总。历史战报按所查看难次计算失败阈值。
- 管理员保留原有内存鉴权、危险操作确认及后台清理；新增兑换码草稿数量/天数/备注表单。

- `npm run typecheck`，`npm run test:minigame`，`node --import tsx --test apps/web/test/*.test.ts`，`npm run build`，`npm run build:minigame`。
- 小游戏测试新增：私密关闭、表决保留选择、任务选牌、独立预设、收藏栏目、资料草稿、发送失败保留草稿、小屏返回/提交可达、固定按钮命中、模态空白拦截、历史规则阈值及匿名票抑制。
