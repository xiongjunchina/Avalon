# 角色插画与身份牌

日期：2026-09-30。

## 实现

为保留的八个角色分别制作一张原创奇幻桌游插画，不含兰斯洛特。沿用深墨、古金及蓝红阵营配色，姓名和阵营由网页文字显示，不绘制在图片内。

| 角色 | 图案识别点 | 素材文件名 |
| --- | --- | --- |
| 梅林 | 白须法师、蓝色斗篷、青色水晶球 | merlin |
| 派西维尔 | 露面骑士、金钢盔甲、长剑 | percival |
| 忠臣 | 铁盔、锁甲、蓝色盾牌 | loyal |

| 刺客 | 红色兜帽、蒙面、匕首 | assassin |

| 爪牙 | 红衣甲胄、短须、战斧 | minion |

展示位置：

- 发牌后点击“私下查看我的身份”，展开插画、阵营、角色名称及一句角色题词；私密视野仍按原规则另行展示。
- 个人中心的角色战绩使用八张角色卡；阵营战绩继续独立成区。
- 终局公开身份及本人有权限访问的历史复盘，在角色名称旁显示小图标。

身份收起时不挂载本人角色插画，也不按本人角色预加载图片。刷新、离开对局页、页面隐藏、断线及步骤变化继续收起身份。其他玩家座位保持通用外观；梅林视野、派西维尔候选及女神查验不会新增准确角色图。通用角色素材本身是公开资源，不承担鉴权职责。

## 素材与加载

- 原图保存在 [`artwork/roles/`](../artwork/roles/)，八个同名 PNG 均由内置 `image_gen` 工具逐张生成并检查。
- 完整最终提示词保存在 [`artwork/roles/prompts.json`](../artwork/roles/prompts.json)。没有复制用户参考截图中的人物原画。
- 网页素材位于 [`apps/web/public/art/roles/`](../apps/web/public/art/roles/)，每个角色提供 160px 和 640px WebP，通过 `srcset` 按显示尺寸和像素密度选用。
- 16个网页文件合计 612,210 字节，约598 KiB；单张大图约49–98 KiB。私密身份图即时加载，列表图延迟加载，固定比例预留空间。
- 图片加载失败时保留原有角色线条纹章，角色名称仍显示；读屏可读取角色图案名称。
- 原始 PNG 与提示词仅供后续维护，`artwork` 已从 Docker 构建上下文排除。运行时无第三方图片服务、新增依赖或字体请求。
- 本次没有修改规则、服务端接口或数据库结构。

## 验证

- `node --import tsx --test apps/web/test/*.test.ts`：9项通过。新增覆盖5–10人全部八角色的默认身份保密，以及终局插画只能来自已公开角色。
- `npm run build`（包含类型检查）：通过。最终构建包含全部16个WebP文件。
- 使用独立的 PostgreSQL 测试 schema 和本机临时服务完成真实五人入座、准备、发牌。浏览器发到莫甘娜：展开后图案正确且已加载；发牌默认收起、手动收起、刷新及从展开状态切换个人中心再返回时，私密插画数量均为0。
- 浏览器确认八张角色战绩插画全部加载成功，阵营／角色仍为两个独立区域，控制台无警告或错误。
- 320px、390px窄屏检查无整页横向溢出；角色卡小屏双列，桌面四列。身份卡在320px视口宽201px，保持完整。测试后恢复默认浏览器尺寸。
- 本机容器版重新构建并更新；测试数据与现有开发／容器试玩数据隔离。
- 本次验证范围为角色素材与前端呈现，没有重复执行数据库故障和完整规则测试。iPhone／Android 微信真机仍待单独验收。
