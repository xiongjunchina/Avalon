# 《话剑》手机单屏布局修正

> 历史记录：用户后续指出区域分配与身份页仍不合格。本轮结论已由 [《论剑》均衡单屏布局验证](lunjian-balanced-ui-validation.md) 替代，当前行为与截图以新记录为准。

日期：2026-10-17。范围：本地 H5 等待房与进行中的对局；没有部署到 Docker/ngrok，没有修改服务端、数据库和游戏规则。

## 问题与处理

在 390×844 浏览器视口中复现六人试玩页面高 1115 像素：中间区域有约 76 像素的强制背景留白、独立景观占位块，以及每张头像上下预留的空行，底部操作落在屏外。前一次仅验证横向溢出不足以覆盖手机单屏要求。

- 等待房和对局采用 `100dvh` 与安全区内边距，根据可用高度收紧任务徽章、队长/出征头像及座位间距。删除景观占位元素，保留六场景背景和较大的金色队长头像。
- 十二人仍显示两排座位；出征 4–6 人仍显示两排青色头像。短视口下出征头像使用席号小标，完整玩家名仍保留在座位、按钮无障碍标签和标题中。
- 组队、表决、出牌的主要按钮和身份/战况/规则入口在屏内。投票选项与确认并排；发言顺序显示席号，去掉与头像阵容重复的文字队伍名单。
- 中断入口保留，确认及全员表决改用弹窗；收到中断表决时收起私密身份和战况，避免叠加弹窗。取消、反对中断和返回对局均可继续操作。
- 620 像素以下可用高度进一步压缩重复提示和装饰，关键按钮保持至少 44×44 CSS 像素。不使用整体缩放或隐藏屏外按钮来制造单屏效果。字体放大、极矮横屏仍保留可滚动兜底，避免内容被裁掉。

使用已有的“UI验收侠”访客和单人试玩。实际创建的十二人等待测试房已退出关闭；演练没有写入真实战绩。

五种手机视口：320×568、375×553、320×667、390×844、430×932。额外六人出征检查包含 1280×800 桌面视口。375×553 用来覆盖地址栏展开后较少的网页可用高度。

断言不仅检查页面宽度，还检查主容器 `scrollHeight <= clientHeight + 1`、页面高度、主要按钮/全部座位/已选头像边界、点击区域大小，以及公共座位不出现秘密角色图片。
