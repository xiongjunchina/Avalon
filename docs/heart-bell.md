# 女妖精法宝：同心铃

2026-10-23 本地实现，未部署或推送远端。

## 玩法

- 当前女妖精配置在 11、12 人局；玉兔精、白骨精、老鼠精、蜘蛛精共用同一能力，房主须开启专属法宝模式。
- 整局一次，只在任务出牌阶段、该任务一张失败牌即可导致失败时使用。当前 11、12 人局的第 3、4 难需两张失败牌，不能使用。
- 使用者须在车队内。目标仅能是一名同车且已相认的其他妖魔，双方都尚未提交本轮任务牌。不能选择自己、好人、牛魔王或车队外玩家。
- 从对局页「法宝」选择同伙，再点「建议护经」或「建议作祟」即发送并消耗次数。无自由输入、无回复、无额外等待期，不强制任何玩家如何出牌。

## 私密交互

- 使用者收到已传给哪位仙友的回执。收件人在前台收到无声的私密提醒，标注任务与组队次数；不显示发送者座位或具体角色。
- 其他玩家没有提示，不改变公共战报、组队票、任务牌或游戏阶段。接收者即使自身无主动法宝（如六耳猕猴），也可从「法宝」回看收到的消息。
- 收件人出牌或离开该轮后标为过时记录。确认已阅不向服务器提交命令，不影响其他人的进度。
- 切后台或断线收起私密弹窗，回到前台后提供中性未读提示；已读标记按对局和用户隔离，仅保存 `read`，不缓存传音内容。
- 单人试玩中，女妖精满足传音条件时，暂缓分身自动出牌，方便体验；仍可自行出牌或点击代操继续。这只是试玩节奏，真实房间不等待法宝使用。

## 实现与兼容

- 沿用 `useTreasure` 命令，增加 `{ action: 'heartBell', targetId, advice: 'protect' | 'sabotage' }`；严格拒绝额外字段。
- 私有状态为 `GameState.treasuresState.heartBell`，保存使用者、目标、任务、组队次数与建议。沿用现有游戏 JSON 持久化、房间锁、版本校验和命令回执事务；无 SQL 迁移。
- 服务端重新检查使用条件。若目标先出牌，则传音失败且不消耗次数；若传音先提交成功，目标随后仍可自主出牌。
- 对外投影仅在使用者 `self.treasures.heartBell` 返回可选对象和发送回执，在收件人 `self.treasures.incomingHeartBell` 返回建议与时效。其他成员和无身份观察者均无此字段，旧存档缺失此可选状态时按未使用处理。
- 观音和同心铃共用私密通知的前后台可见性、已读处理，保留各自独立的存储键。
