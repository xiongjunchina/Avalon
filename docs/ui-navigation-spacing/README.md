# 规则导航、等待页间距与预选文案验收

验收环境：本机 Vite + Chromium，使用模拟房间数据；未连接或修改 ECS 房间。

- 规则与角色页：仅 50px 高的单行工具栏吸顶，提供返回、规则/角色切换、章节选择和返回目录。完整目录置于正文顶部，随正文滚动；正文始终直接展示。锚点避让按工具栏实际高度计算。
- 规则配置：5–12 人配置全部直接显示，移除折叠组件。
- 等待、对局与试玩页：移除对浏览器顶部安全区的额外留白；手机首栏距网页顶部为 4px。顶部三栏共用 4px 间距，大屏为 8px，配置摘要高度与对局摘要对齐。
- 组队阶段：发言前为“预选阵容”，顶部提示为“待提交预选”；论道后仍为“已确认阵容 · 开启投票”。

验证：`npm run build`、`guide-countdown.test.ts` 的 3 项相关测试，以及浏览器布局检查。

| 检查 | 覆盖范围 | 结果 |
| --- | --- | --- |
| 等待 / 预选 / 论道 | 5、8、12 人 × 320×568、375×553、390×844、430×716、640×900 | 45 组通过，间距一致，无横向溢出 |
| 非零顶部安全区 | 模拟 44px，覆盖等待、未准备、对局预选/论道、试玩预选/论道 | 6 组通过，首栏距网页顶部仍为 4px |
| 规则 / 角色导航 | 同上五种视口，逐一跳转 6 个规则章节、9 个角色 | 工具栏均为 50px 高，控件可见，目标未被遮挡，目录与原页面可返回 |
| 配置展开与阶段文案 | 直接渲染规则、游戏状态流转与浏览器检查 | 通过 |

详细结果：[viewport-audit.json](viewport-audit.json)。复测时启动 `npm run dev:web`，打开本机 Vite 页面，通过 Playwright 的 `browser_run_code_unsafe` 运行 [viewport-audit.playwright.js](viewport-audit.playwright.js)。脚本仅拦截本机接口并生成模拟数据。

安全区模拟方式：在浏览器加载样式时，将 CSS 中的 `env(safe-area-inset-top)` 替换为 44px。旧样式因此产生 44px 顶部空白；修改后首栏保持在 4px。该检查用于覆盖非零安全区条件，不能替代用户手机浏览器的发布后复测。
