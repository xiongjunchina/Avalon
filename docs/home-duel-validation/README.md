## 构图与范围

手机依次排列标题、人物、宣传句与操作；短屏收紧人物区高度，人物图用 `contain` 完整显示。电脑将人物分置两侧，中央留出宣传文案与操作空间。新增样式仅用于首页，新人物插图为透明 WebP，沿用原天宫背景，没有加入整块文字底板。

创建、加入、单人试玩、语音模式、按需登录、邀请、仙友、声音、个人中心及辅助入口保留原回调。游客和登录用户共享相同主视觉。活动横幅继续受系统配置控制。原轮播状态与3.8秒定时器已删除，避免持续渲染／下载额外角色。

## 验证结果

- 相关组件／入口测试5项、图片与字体预算测试2项通过。
- `APP_BASE_PATH=/avalon/ npm run build` 类型检查与生产构建通过；构建仍提示现有主包／Agora分包大于500KB，本次未改变这些模块的加载策略。
- 独立Chromium验证320×568、375×553、390×740、430×800、640×900、760×900、1440×900；另覆盖登录用户、带邀请、关闭活动横幅，共11种状态。无页面横向溢出、文字内部截断或脚本错误，两款本地字体实际加载；人物图片均使用 `contain`。
- 所有上述尺寸的开房／加入按钮在首屏可见：320短屏底边约429px，375短屏约427px，390常规约547px；最终邀请状态约571px。主按钮高度48px（电脑50px），模式按钮44px。
- 模式切换保留；游客开房／加入／试玩进入对应身份流程；模拟已登录用户可打开建房设置。未创建真实账号或房间。
- 停留超过旧轮播周期后主视觉不变，没有加载旧轮播角色图片。
- 最终生产构建在本机 `/avalon/` 子路径复核390游客、390邀请和1440电脑视图；人物图与两款字体均从正确子路径加载，邀请提示已改为透明底深色字。
- 独立复核过手机、电脑、断点与邀请截图，人物头部、头冠长翎及面部没有裁切，文字不遮挡脸部。见 [几何数据](results.json)。

可复用 `browser-check.mjs`：需现有Playwright安装、本机Vite开发／生产预览服务；设置 `PLAYWRIGHT_MODULE` 可使用已安装模块，`HOME_REVIEW_FIXTURE` 可按标签筛选增量场景。脚本拦截全部API为测试数据，阻断外部字体以验证本地字体，不访问ECS。
