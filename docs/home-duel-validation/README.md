# 真假猴王首页：按确认稿重新落地
2026-10-31。此记录取代首版“小胸像＋空白”方案的验收结论。

用户确认的是大幅近景对峙；首版把人物做成缩小透明胸像，并用“contain、没溢出、按钮可见”代替了与原稿的视觉核对，偏离了确认稿。本轮以原稿为构图来源，重新提取完整无字场景，再叠加真实HTML文字和控件。

## 与设计稿的核对
- 手机：两侧大幅人物脸部和上半身延续贴边近景；允许原稿已有的外侧肩甲／长翎取景，不再为塞进整尊人像而缩小人物。主口号明确分为两行，390px下约42px，使用书法字体与轻微笔画加厚。
- 电脑：同样采用完整连续场景、左右大幅人物、中央标题和宣传句；模式、开房、试玩与导航的大小及纵向位置已向原稿校准。模式区约66%H，主按钮约74%H。
- 手机模式／主按钮／试玩／导航约在68%／76%／85%／95%H，底部不再保留大块空白。
- 声音入口在首页显示带文字椭圆，保留打开声音设置的原行为；最窄登录态可收起文字，避免挤压。
- 活动小横幅及系统开关是明确保留的业务项目，原稿未绘制该横幅。
- 已独立人工对照手机和电脑截图；结论是人物比例、层级与主要位置近似匹配，不宣称生成插画与原稿逐像素相同。
