# 5秒发牌倒计时与玩法指南

日期：2026-09-30。

## 完成内容

- 房主开局后全员显示5→1倒计时，结束后才出现“私下查看我的身份”。身份不会自动翻开，仍需本人操作。
- 服务器在开局事务内只分配一次身份，同时保存5秒截止时间；页面刷新、断线重连和服务重启沿用原截止时间与原身份。
- 倒计时期间锁定席位和玩法，不能提前确认身份、投票或中断；结束后恢复原有操作流程。
- 页面以服务器快照时间加本地单调计时计算剩余秒数；显示到0后等待服务器确认，不自行解除保密。服务写入失败时保留倒计时阶段并重试。
- 主导航增加“玩法指南”，首页未登录、等待房间、对局和个人中心均可进入。返回原页面，房间连接保留；从私密身份切到指南再返回时，身份收起。
- 游戏规则覆盖胜负、准备与发牌、组队讨论、全员表决、匿名任务、刺杀、5–10人角色和任务人数、房间设置与两项拓展。
- 角色介绍包含梅林、派西维尔、忠臣、莫甘娜、刺客、莫德雷德、奥伯伦、爪牙，按阵营分区。每张卡展示插画、能力与视野、谁能看见该角色及玩法提示。没有兰斯洛特内容。
- 人数配置与任务人数复用规则引擎常量。指南不读取本局个人身份，不改变规则。

## 自动化验证

`npm test`：**69项通过，0失败、0跳过**，使用真实PostgreSQL与独立随机测试schema。

新增验证包括：

1. HTTP与重新加入接口在截止前不返回任何玩家的私密角色，提前确认／中断被拒，设置保持锁定。
2. 同一startGame命令重放保持原游戏和截止时间；新编号再次开局被拒，数据库仅一条游戏记录。
3. 4999ms时不能开放身份，5000ms后并发唤醒仅提交一次，版本号只增加一次。
4. 服务重启后保存原截止时间、重建计时器，两个WebSocket玩家收到各自正确的原始角色。
5. 到期写入失败不改变阶段、版本或身份可见性，恢复后只推进一次。
6. 五个真实WebSocket连接共享同一截止时间，正常startGame自动安排实际5秒计时器并广播完成。
7. 指南包含八角色、关键视野例外、标准与拓展规则，排除移除角色；前端倒计时使用服务器时间，不显示提前查看／确认按钮或角色图片。

原有对局、拓展、身份隔离、恢复、战绩、会话、越权、数据库故障及部署配置测试一并通过。构建含类型检查通过。
