# 微信小游戏原生实时语音

## 已确认方案

小游戏使用微信原生 VoIP；网页继续使用声网。两套语音不互通，游戏牌局状态仍共享。

2026-10-30 已读取微信官方实时语音文档：每个语音房最多同时加入 **10 人**。11～12 人牌局仍可正常玩，但本实现不允许加入原生语音，避免只允许部分玩家听到讨论。没有采用拆分语音房等不完整替代方式。

- 官方指南：https://developers.weixin.qq.com/minigame/dev/guide/open-ability/voip-chat.html
- API：https://developers.weixin.qq.com/minigame/dev/api/media/voip/wx.joinVoIPChat.html

## 使用方式

1. 使用当前微信绑定的游戏账号登录，创建或加入 5～10 人房。
2. 点击顶部声音按钮，在声音设置内点击「加入微信语音」。
3. 同意微信隐私与麦克风授权；默认关闭麦克风，主动点击「开启麦克风」后发言。
4. 可暂停收听、查看语音成员及说话人数、主动退出语音。
5. 切房、退房、断线、设备接管、退出登录或退后台时退出语音。返回前台需主动再次加入，不自动开麦。

暂不提供跨端语音。使用仙友码切换到不属于当前微信绑定的账号时，签名接口拒绝加入语音，并提示重新微信登录。

## 服务端

新增 `POST /api/rooms/:id/wechat-voice-ticket`，仅接受已认证 bearer 会话和一次性微信 code。服务端核验房间成员和当前微信 OpenID；限制房间配置最多10人；微信换取 session_key 后再次核验成员状态，再使用 HMAC-SHA256 签发 groupId、nonceStr、timeStamp、signature。客户端不能指定 groupId、OpenID 或签名参数。session_key 不持久化、不返回客户端、不传入普通登录回调；AppSecret 继续使用服务器私有环境变量。

原有 `/voice-token` 声网端点、网页语音和房间 voiceChatEnabled 设置不改变。原生语音按小游戏用户主动加入启用，独立于网页声网开关。

## 上线前必须完成

- 部署包含新增签名接口的后端。只更新小游戏包不足以启用语音。
- 微信公众平台「游戏能力地图 → 实时语音」申请接口权限；当前 AppID 是否已经获批尚未验证。
- 在微信后台用户隐私保护指引声明麦克风用于同房实时语音；包内已有 scope.record 用途声明。
- 使用备案域名及合法域名配置，在至少两台手机验证真实双向通话、拒绝授权、来电/退后台、重入、断线、满员；十人上限来自官方文档，未做十台手机实测。
- 本轮不上传、不正式发布，不承诺未经真机验证的通话可用性。

## 验证范围

自动化覆盖签名身份与成员授权、拒绝11/12人、会话密钥不外泄、入房默认闭麦、麦克风授权拒绝、成员变化、切房退出、异步入房取消、扩容后退出。语音需要微信平台权限和真机环境，不能用模拟接口测试代替真实通话验收。
