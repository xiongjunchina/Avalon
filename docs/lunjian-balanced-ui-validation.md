# 《论剑》均衡单屏布局验证

日期：2026-10-17。本记录替代上一轮“仅检查不溢出”的单屏布局结论。范围为本地 H5 页面；没有更新 Docker/ngrok。

## 本轮修改

- 登录首页、大厅、页面标题与玩法指南统一使用“论剑”。首页副标题仅保留“国风武侠推理桌游”并居中，删除“以话为剑”。历史素材路径、数据库标识和旧验证文件名不改动。
- 对局按任务进度、队长与出征阵容、玩家席位、操作栏四个区域分配高度。中间两区按比例分享可用空间，去掉把剩余空间集中在底部的自动外边距。队长大头像与独立出征区继续保留。
- 头像尺寸取决于实际区域宽高及人数。常见竖屏的 9–12 人采用四列三排；可用高度较少时改为两排。未满一排的 5、7、9、10、11 人布局居中。姓名保持完整行高，过长昵称使用省略号与完整标题。
- 入选头像使用青色边框，删除重复“入阵”浮标与叠加光环，在线状态默认不重复绘制绿点，离线仍有标记。队长、明镜、座位号与公共投票状态继续可辨。
- 试玩视角从大号下拉框改为小型按钮与席位弹窗；发言方向改成顺时针/逆时针分段按钮。弹窗支持 Escape、焦点恢复；方向实际传入组队命令。
- 私密身份改为横向角色卡、独立身份视野、必要的特殊操作及底部提示。头像名单不再用长段落重复列出；不推断他人的准确角色。明镜确认状态只保留一个主要确认按钮。提前刺杀及与明镜叠加时也按内容量调整布局。
- 明镜阶段没有出征阵容时，不再预留整块空阵容区。查验仍按原权限执行。
