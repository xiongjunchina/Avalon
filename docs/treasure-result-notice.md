# 法宝入口与观音私密结果提醒

2026-10-23，本地实现；尚未部署线上。

- 所有已发牌角色的对局工具栏均只展示“法宝”二字，移除副文案与角色相关的悬停/读屏提示，具体法宝信息在打开后查看。未满 8 人、房间未开启法宝或角色没有主动法宝时禁用；红孩儿保留原有刺杀神兵入口，不受拓展法宝开关限制。
- 有法宝但未到使用时机，可以打开说明，发动操作仍遵守服务端的阶段和次数限制。对局结束后可以回看，不可发动。
- 新开 `v6` 对局同时开启护法天机和法宝时，蓝方法宝禁用、红方法宝保留；未开启护法天机时双方依原法宝规则。本人私有投影区分组合模式禁用与全局未开启，详见[组合规则](guardian-treasure-balance.md)。
- 观音成功查验后直接收到私密结果卡，展示目标头像、座位、昵称和阵营，不展示具体角色。只使用服务端投影到本人 `self.treasures.guanyinMirror.result` 的信息。
- 结果卡无自动关闭计时，也不播报音效。本人确认后才显示同一时刻到达的公共任务战报；其他玩家继续原有流程。
- 点击对局页“法宝”直接回看观音查验结果。身份页原有入口仍保留。
- 后台或断线时收起结果；返回后以按钮上方无敏感内容的提醒提示主动查看。
- 已读标记按对局 ID 和玩家 ID 保存在当前浏览器，只保存 `read`，不缓存目标或阵营；刷新、重连不会重复提醒已读结果。清除浏览器存储或换浏览器会再次提示。存储不可用时保留当前页面内的已读状态。
- 不增加服务端命令、数据库迁移或全房间确认步骤。

后续同心铃扩展：女妖精新增主动法宝，收到同心铃传音的角色即使没有自己的主动法宝，也开放该入口用于私密回看。通知可见性与已读逻辑已抽到 `private-notice.ts` 复用，观音规则保持不变。详见 [同心铃实现记录](heart-bell.md)。
