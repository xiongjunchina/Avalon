# 个人资料头像与字号验收

- 用项目已有的 12 张法宝道具图替换旧符号选择框，直接展示名称、图片和选中状态，支持预览后保存。
- 去除“仙友人物头像”的误导性文案和逐张轮换按钮；自定义照片继续优先显示，关闭未保存的编辑不会修改资料。
- 旧六种头像值保留兼容，在未使用照片的旧资料上显示相应法宝图，无需改动数据库结构。
- “昵称”“预置头像”、昵称输入框及正文均为 14px。列表在内容区滚动，标题、关闭与保存按钮保持可见。

验证结果：生产构建通过；64 项前端测试通过；另在最终文案调整后复测 5 项账号/头像测试。
