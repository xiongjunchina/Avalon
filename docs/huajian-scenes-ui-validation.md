## 对局组合与战况

- 恢复并保留「大号金色队长头像 + 青色出征槽位」横幅，结合上方五岳徽章与下方玩家头像列表。队长只有被明确选中才计入队伍；队长可在横幅移除已选成员，非队长和已提交方案不能修改。
- 出征槽位支持 2–6 人，4–6 人时为两排，六人槽在 320 像素宽度仍完整可操作。五岳始终显示 1–5 数字、人数、进度及实际失败门槛，图案使用独立 SVG ID 避免弹窗和主界面冲突。
- `BattleRound` 共用于单轮详情、全部战况和历史复盘，按「组队方案 → 组队表决 → 任务结算」分段展示。
- 公开组队投票显示全员头像与勾/叉、短文字，而不仅仅显示出征成员。匿名模式仅保留队长和出征队伍头像、席号、昵称；投票仅显示总数，即使收到含 ballots 的数据也不渲染个人票型。
- 尚未公布的投票不显示个人选择；公开记录缺少某张票时不将其当成反对。任务牌在两种模式下始终只显示总数，不对应任何玩家。
- 所有公开头像来自账号信息；历史数据缺少头像、或头像加载失败时回退到中性徽章，不用秘密角色图案补位。既有角色画像继续用于私密身份、通用角色说明和终局公开身份。
