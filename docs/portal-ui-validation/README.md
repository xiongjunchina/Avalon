## 手机修复

- 旧的640×640方图被放入约366×310卡片，`cover + bottom`额外切掉顶部；现在卡片跟随各源图比例，手机图片使用`contain`完整显示。
- 嘻游原素材头冠／长翎已触及源图边缘，因此重新构图并补足四周空间；暗局人物同步收拢，给发顶、肩部留出余量。两图仍只发640px宽。
- 按用户明确要求，将宣传句／说明改成14px／13px，人数11px、按钮14px；使用游戏现有字体家族的小薇体常规字重，关闭合成粗黑。人数与进入按钮同行，保留44px点击高度。
- 390px宽文字区占两封面约35.9%／34.4%，320px约43.3%／41.4%；文字位于人物面部以下，无大面积实色底板。

图片通过内置图像生成工具，参考已确认效果稿和原角色素材生成无文字背景，再压缩为上述发布资源；提示词记录见 [art-prompts.md](art-prompts.md)。本目录截图与提示词不在 `deploy/portal/assets`，不会随网页下载。
