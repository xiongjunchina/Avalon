图片通过内置图像生成工具，参考已确认效果稿和原角色素材生成无文字背景，再压缩为上述发布资源；提示词记录见 [art-prompts.md](art-prompts.md)。本目录截图与提示词不在 `deploy/portal/assets`，不会随网页下载。
