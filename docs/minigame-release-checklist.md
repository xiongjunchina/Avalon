## 生成并导入工程

在仓库根目录执行：

```powershell
npm run package:minigame -- --version=0.1.0
```

输出位于 `dist/releases/minigame-0.1.0-<随机后缀>`。导入其中的 `project` 文件夹，工程类型选择“小游戏”。同级 ZIP 是该版本的备份。不要把仓库根目录或 ZIP 直接作为开发者工具工程。

`release.json` 记录具体提交、工作区是否干净、API 地址、AppID、原始包大小及全部工程文件的 SHA-256；若后续改代码或服务地址，需要重新打包。
