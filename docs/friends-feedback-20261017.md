# 2026-10-17 朋友实测反馈修订

本次修改已完成验证，并已发布至本地 Docker / Ngrok 公网及推送至 GitHub。

## 已实现

1. 战况按时间顺序显示全部提案与结果，纵向滚动查看，单条记录保持紧凑；不再仅渲染选中的一条。压缩队长、队伍、全员票型与任务结算。规则、角色页同步缩小字号、行高及间距。
2. 五轮任务成功绿底对钩、失败红底叉号；人数移到圆框下方，初始山形与结果不再被遮挡。
3. 个人中心两项折叠标题统一为15px及同一行高、内边距。
4. 队长预选立即持久化、广播；讨论和总结时可修改同一提案，发起投票才锁定。其他玩家只读查看。
5. 增加弃权，按用户最终确认执行：赞成多于反对即通过；弃权不参与比较，平票和全弃权不通过。自动弹出投票窗口，展示全员提交状态；公开模式实时展示个人选择，匿名模式不包含个人票型。3秒后标识未投玩家。等待房间未准备5秒提醒本人，满员后仅剩本人未准备则立即提醒。
6. 房主直接结束，或批准其他玩家申请；同一事务记录不计胜负的中止结果、关闭房间、解除全部席位。在线端收到关房消息回大厅，离线端刷新也不再恢复旧房间。
7. 5–7人默认匿名，8–12人默认公开；房主开局前仍可手动覆盖或应用预设。
8. 风清扬身份牌依据本局公开配置：7–8人说明所见为全部暗影成员，9人以上才提示岳不群的视野例外。
