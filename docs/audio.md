## 新版音效

`apps/web/public/audio/v3/` 共 15 个原创建模音效。强调手游常见的清晰起音、战鼓、锣声、金属冲击和号角层次，没有复制其他游戏录音。

| 场景 | 音效 |
| --- | --- |
| 所有可用按钮、头像选择、单选/复选、下拉选择、展开项、键盘操作 | 中性金属与木质点击声；禁用控件不响 |
| 页面、个人中心栏目、规则分类、弹窗开关、战况轮次切换 | 掠风与金属短响 |
| 发牌倒计时 | 发牌音与最后三秒轻叩 |
| 倒计时完成进入对局，或进入单人试玩 | 3.2 秒战鼓滚奏、号角和锣声 |
| 进入公开刺杀状态 | 2.7 秒立即金属重击、快速拔剑、锣与低鼓尾音 |
| 本人胜利 | 5.6 秒快速双层号角、密集鼓点、连续上行旋律与大和弦收尾（victory-r2） |
| 本人失败 | 3.7 秒下行小调、低鼓与沉重金属收束 |
| 中断或没有玩家视角的结束状态 | 2.2 秒独立结束锣声，不播放胜利或失败 |
| 公开组队与任务结果 | 简短提示、成功清响或失败低音，与整局终章区别 |

胜负以 `result.winner` 和当前玩家阵营比较，仅在公开结果首次出现时使用阵营。同一局不同阵营的玩家听到不同结算音效；切换试玩视角、刷新、重连不补播。未结束时的个人角色、出牌内容和查验结论不触发差异化音效。投票赞反、任务成功失败等选项均使用相同的中性点击反馈。

普通操作与重要节点采用独立声道和优先级：结算高于刺杀，刺杀高于开局。普通点击、导航和弹窗不会打断重要音效，但仍有较轻的操作反馈。重要音效期间背景音乐固定压低到 0.025；结束后恢复普通或刺杀阶段混音。关闭音效或进入后台同时停止声音并取消在途请求。

生成命令：`node scripts/audio/generate.mjs`，制作工具为 Node 和 ffmpeg；运行游戏不需要安装它们。v2 旧操作音效已删除，背景曲保持原文件；新效果用 v3 路径避开旧缓存。

## 验证

- 25 项前端测试通过，其中 8 项音频测试验证开局时机、重复快照、恢复不补播、本人胜负（双方阵营与中断）、音效优先级、独立开关和异步取消。
- 浏览器实际验证：进入试玩播放开局音，打开身份弹窗时开局音未被打断；按钮、单选、复选、下拉、头像、展开项、链接与键盘控件均可解析反馈，禁用控件无声。
- 浏览器实音验证：刺杀音不被点击或转场打断；结算可接替刺杀；胜利音不会被页面音打断，胜利和失败加载不同文件。验证后声音开关恢复关闭。
- 本次仅检查音频交互与构建，没有重复验证旧版尺寸矩阵或数据库。手机实际音色仍待用户试听。
