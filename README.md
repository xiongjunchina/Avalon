# 论剑 · 国风武侠推理桌游

独立手机网页，适合朋友线下同桌。分享链接、各自手机入座，面对面讨论。无小程序、微信认证、内置语音或商业化功能。

## 当前状态：游戏功能已实现，进入 Docker + ngrok 朋友内测

- 访客身份、等待房间、设置和准备状态保存在 PostgreSQL，服务重启后恢复。
- 邀请链接／房间码直接加入；房主可关闭新成员加入，原成员仍可重连。
- 30天滑动会话、事务与幂等回执、断线恢复、房主转交、全员离线24小时清理。
- 5–12 人安全随机发牌、角色私密视野、组队讨论、表决、匿名任务出牌、流局判负、正常刺杀与结算。
- 对局及已提交的票跨重启恢复；结束后可同房再开，原局记录保留。在线成员一致同意可中断，不计胜负。
- 可选少林明镜：第2、3、4个任务后查验阵营、交接并排除历任持有人；结果仅查验者可见。
- 可选提前刺杀：完成两个实际任务后，林平之可从私密身份页启用；立即进入刺杀阶段，命中风清扬则红方胜、未命中则蓝方胜。
- 个人中心支持昵称、预置及上传头像、胜负与角色／阵营统计；中断局单列，零局胜率显示“—”。
- 九个角色配有人物插画，展示于私密身份牌、角色战绩及终局／复盘。公共席位使用玩家头像，角色身份保持私密。
- 发牌前全员同步5秒倒计时，刷新／重启沿用原截止时间，结束前不开放身份。“玩法指南”提供完整规则和九角色图文介绍，未登录也可查看。
- 历史与收藏只对本局参与者开放。复盘显示当时昵称、最终身份、逐轮队伍与表决、匿名任务总票数、明镜和刺杀记录。
- 常用设置最多10个，同名保存更新；房主在等待区应用后重置准备，仍受人数、版本和权限校验。
- 独立容器部署、同源网关、本地HTTPS、备份校验与空库还原已实现；原开发数据保持独立。已增加独立 ngrok HTTPS 朋友内测实例，微信真机朋友局与后续ECS正式部署单独验收。

朋友内测入口与启动／停止方法见 [Docker + ngrok 朋友内测](docs/friends-test.md)。先完成朋友手机上的完整对局，再购买 ECS；目前不修改已有域名解析。

当前仓库已统一为《论剑》与六场景国风背景，保留大号队长头像和独立出征阵容。对局及身份页按人数和可用高度分配空间；战况区分公开与匿名投票。最新实拍与检查见 [均衡单屏布局验证](docs/lunjian-balanced-ui-validation.md)，场景分配与战况说明见 [六场景界面记录](docs/huajian-scenes-ui-validation.md)。本轮仓库更新不同时更新 Docker/ngrok，手机多人实局继续单独验收。

## 首次启动（本机）

需要 Node.js 22.12+ 与可用 Docker。命令均在项目根目录执行。

```sh
npm ci
npm run setup:local
npm run db:up
npm run db:migrate
npm run dev
```

打开 **http://localhost:5173**。默认 Origin 校验只接受该地址，勿混用 127.0.0.1。前端5173、后端3001、数据库55433均只监听本机，未发布局域网或公网。测试不同玩家需使用不同浏览器会话；同浏览器标签共享身份，新标签会接管旧连接。

`setup:local` 生成忽略提交的 `.env`，随机数据库密码不会打印。现有 `.env` 不会覆盖。后端、迁移和测试自动读取 `.env`；数据库账号与数据存于 `avalon_avalon_pgdata` 卷，不能通过修改 `.env` 自动变更已有数据库密码。

开发服务启动时自动执行尚未应用的迁移，迁移失败则不启动。`Ctrl+C` 停止前后端；`npm run db:stop` 停止数据库并保留卷。后续运行 `npm run db:up` 和 `npm run dev` 即可恢复。不要执行带 `-v` 的 Compose down，否则会删除数据库卷。

## 独立容器试玩（本机）

```sh
npm run deploy:setup -- local http 8088
npm run deploy -- local build
npm run deploy -- local up
```

打开 **http://127.0.0.1:8088/**，与5173开发版使用不同数据卷及浏览器身份；同一主机名不同端口的Cookie并不隔离。停止用 `npm run deploy -- local stop`，不会删除数据。数据库和后端没有主机端口映射。HTTPS、备份还原、升级回退和公网模板见[部署指南](docs/deployment.md)。本机地址尚不能分享给手机或远方朋友访问。

## 本地试玩

各玩家使用独立浏览器会话进入同一房间，准备齐后由房主发牌。全员倒计时5秒后，私下查看身份并确认，按页面提示完成队长组队、讨论、全员表决、任务和刺杀。默认按座位轮换队长、全局累计五次流局判红方胜；任务投票始终匿名。7–10 人第四个任务需两张失败牌才失败。随时可打开“玩法指南”；返回后身份默认收起，座位和对局进度保留。

开局后设置和席位锁定。掉线保留座位，刷新可恢复；不能用退出房间跳过自己的回合。确实无法继续时可以请求中断，当前在线成员一致同意后公开身份并保留中断记录。仅一人在线时，其确认请求即可中断；成员上下线或其他游戏操作使未完成请求取消。结束后房主可返回等待区，全员重新准备；接纳开关保留原设置。

表决／任务提交一经服务器接受不可修改。并发操作遇到版本冲突时先同步状态，再由玩家重新确认；网络断线造成回执不确定时只重放原命令编号，不产生新选票。

湖中女神建议7人以上，也允许5–6人启用。持有人查验后，须在私密身份面板查看并确认结果；查验对象成为下一位持有人，历任持有人不可再次被查。查验和结果确认均支持刷新／重启恢复。

提前刺杀窗口的公共提示统一为“轮间确认中”，只有刺客的私密面板显示跳过／发起按钮。发起后进入刺杀选人，不能再跳过。终局优先：三次任务失败、五次流局直接红胜；三次成功进入正常刺杀；非终局才依次执行女神查验与提前刺杀窗口。

## 个人中心与复盘

点击顶部“个人中心”查看统计、历史、收藏和常用设置。统计从已结束对局即时查询，不使用累加计数；返回等待区或房间关闭后仍能查阅自己参与的旧局。历史每次加载10条，可以继续加载；收藏记录按对局结束时间倒序。

在复盘底部收藏或取消收藏，取消不删除对局。匿名组队只显示汇总，实名组队显示当时公开的赞反；任务票始终只有总数，未完成投票不展示个人选择。资料修改会同步当前房间名片，已经开始的对局保留开局昵称。

在“常用设置”新建或编辑预设，或在房间的“常用设置 · 保存与应用”中保存当前玩法。预设不保存邀请、成员或接纳开关；同名覆盖原预设，删除不改变房间。只有等待区房主可以应用。

## 数据与恢复边界

- 用户凭证为 HttpOnly Cookie；服务器只保存其摘要。前台每15分钟、切回页面及已认证HTTP请求续期。连续30天未使用过期；换浏览器或清除身份后无法找回旧访客，无密码或恢复码。
- 同一数据库只允许一个活动后端；用数据库咨询锁防止第二个实例重置在线状态。数据库连接中断若导致所有权锁丢失，后端会拒绝服务；恢复数据库后需重启后端，不会自动切回内存。
- 心跳每15秒；确认掉线后保留房主60秒，再转交最早加入的在线成员。重启提供60秒重连宽限。进行中的房间全员离线满24小时后记为中断再关闭，已结算局不会改写；关闭房间不删除用户资料；命令回执在关房30天后清理。
- `003_accounts.sql` 增加用户头像、历史参与者索引、收藏与常用设置，并从已有games名单回填参与资格；不删除旧记录。开局与名单索引同事务写入，历史访问不依赖当前房间席位。
- 新局规则版本为 `standard-no-lancelot-v2`，第四阶段已有v1标准局继续恢复，不重发身份、不自动添加拓展。拓展数据存于既有games状态中；第六阶段增加003迁移，无需清空数据库。
- 尚未迁移第二阶段内存演示数据。无需尝试恢复原临时房间；从第三阶段创建的身份和房间开始持久保存。
- iPhone／Android 微信真机仍待朋友验收。公网 HTTPS/WSS 技术检查与朋友真实手机体验分别记录，见 [内测验证记录](docs/friends-test-validation.md)。
